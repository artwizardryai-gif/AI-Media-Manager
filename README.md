### **AI Media Manager**

AI Media Manager is a Chrome extension for organizing, reviewing, comparing, and downloading media generated with ChatGPT and Grok.

Instead of manually opening generations one by one, AI Media Manager builds a visual catalogue of your media and gives you tools to sort, rate, classify, compare, select, and download it in bulk.

It is designed for people with large generation histories who need a faster way to find the useful results among hundreds or thousands of images and videos.

**Overview**

AI Media Manager can connect to your existing ChatGPT or Grok session and build a catalogue of the media available in your account.

It can also work with local files, allowing the same organizational tools to be used with images and videos already stored on your computer.

**Installation**

AI Media Manager is currently distributed as an unpacked Chrome extension.

Google Chrome on Windows or macOS
Download the latest AI Media Manager ZIP file.
Extract/unzip it to a permanent folder on your computer.
Open Chrome.

Go to:

chrome://extensions

<img width="345" height="262" alt="Image" src="https://github.com/user-attachments/assets/b5c4691e-6b73-4562-87f2-f60eb51d6512" />

Enable Developer mode in the upper-right corner.

<img width="246" height="122" alt="Image" src="https://github.com/user-attachments/assets/ef6fa296-26aa-4a24-8237-c0a9c319b646" />

Click Load unpacked.

Select the extracted AI Media Manager folder.

The extension should now appear in Chrome.

Important: Select the extracted folder, not the ZIP file itself.

You can optionally pin AI Media Manager from Chrome's Extensions menu for easier access.

Using it with ChatGPT or Grok

Log in normally to the official ChatGPT or Grok website in Chrome.

Then open AI Media Manager, choose the appropriate source, and click Connect.

If a Grok tab is already open, AI Media Manager can use it. If one is required and none is open, the extension can open the appropriate Grok page for you.

**Download Overview**

AI Media Manager provides several ways to download your media, depending on how much control you need.

<img width="586" height="114" alt="Image" src="https://github.com/user-attachments/assets/6109bb79-fc5f-472c-8cea-b48d3eac6c06" />

**Download All / Missing**

For large libraries, the download tools can be used to retrieve media from the catalogue without opening every generation manually.

The extension keeps track of the media it knows about, making it easier to work through a large collection over multiple sessions.

**Missing downloads**

The Missing option is useful when you have already downloaded part of your collection.

Instead of intentionally downloading everything again, AI Media Manager can concentrate on items that are still missing from the selected download destination/workflow.

This is especially useful for large Grok or ChatGPT histories.

**Choose Folder Once**

For supported download modes, Choose Folder Once allows you to select the destination folder at the beginning of the download session.

Instead of Chrome asking where to save every individual image or video, you approve the destination folder once and AI Media Manager can continue placing the requested files there.

This makes large downloads much less tedious.

Depending on your browser and Chrome permissions, Chrome may ask you to confirm access to the folder.

**ZIP Downloads**

Media can also be collected into ZIP archives when appropriate.

This can be useful when:

transferring a group of generations to another computer;
creating an archive of a project;
downloading a specific category;
keeping a selected group of images together.

For very large libraries, direct folder downloads may be more convenient than creating one extremely large ZIP.

Privacy

AI Media Manager does not require an OpenAI or xAI developer API key.

It works with the browser session you are already signed into on the official ChatGPT or Grok websites. You do not need to enter your ChatGPT or Grok password into AI Media Manager.

The extension does not create a separate AI Media Manager cloud account.

Organizational data such as categories, ratings, selections, settings, and comic projects is stored using Chrome's extension storage. Local-file workflows operate on files you explicitly choose.

AI Media Manager needs access to the relevant ChatGPT/Grok pages in order to catalogue and download media, so users should always review the permissions of any browser extension before installing it.
