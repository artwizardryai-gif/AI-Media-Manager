AI Media Manager Help

A practical guide for organizing AI images and videos without technical setup.

Quick start

  1. Choose ChatGPT, Grok or Local Files at the top.
  2. For ChatGPT or Grok, make sure you are signed in to the normal website in Chrome.
  3. Click Connect. The catalogue is created or updated from that source.
  4. To check for newly generated media later, simply click Connect again. Connect is the refresh; there is no separate catalogue Refresh button.

Grok: if a Grok tab is already open, AI Media Manager reuses it. If there is no Grok tab, it can open grok.com/imagine/saved for the signed-in page connection.

Sources

ChatGPT builds a catalogue from your ChatGPT image history. Grok reads your Imagine history from the signed-in Grok web session, including generated image/video metadata such as prompts, dates and available thumbnails. Local Files indexes folders you choose on your computer.

Open source opens or focuses the source website. It is useful if you need to sign in or want to inspect the original media.

Selecting media

Selection is the basis for bulk actions. Click the small selection control on a card, or Ctrl/Cmd-click a card, to add or remove it from the current selection. Select visible selects the cards currently shown by your filters; Clear selection clears the working selection.

Once items are selected you can download only those items, place them in a collection, compare them, or add them to Comic Canvas.

Filters, search and sorting

All / Missing / Downloaded / Failed filter the catalogue by local download status. Search matches prompts, dates, URLs, statuses and collection names. Reset view clears the search and returns to the normal main view.

The Sort menu can order by newest/oldest date, prompt, status, or your personal rating. Grid/List, Infinite/Pages and Grid size only change how the catalogue is displayed; they do not change the media itself.

Collections — your custom categories

Collections are custom categories such as Characters, Favorites, Project A, Needs edit or anything else you want. A media item can belong to more than one collection.

  1. Click New to create a collection.
  2. Select one or more media cards.
  3. Choose the destination under Target, then click Add selected.
  4. Use the Filter dropdown to view one collection, all collections or unassigned media.

Rename changes the collection name. Hide from Main keeps the collection and its assignments but removes those items from the normal Main View. Delete deletes the collection assignment structure, not the original media on ChatGPT, Grok or your disk.

Rating / ranking

Open a media card to see the larger preview and the Rating slider. Ratings run from 1 to 5 and are your private organizer score; they do not rate or modify the source post. Ratings are also available inside Compare.

Use Rating high → low in Sort to turn the catalogue into a ranked shortlist. Clear rating returns an item to Unrated.

Compare

Select at least two items and click Compare. The left and right rails choose which selected items are A and B. Side by side works with images and videos; Reveal gives a draggable before/after split when both A and B are still images. Swap exchanges A and B.

You can rate items while comparing them, which is useful for choosing the best generation from a larger batch.

Downloads and status

Download missing downloads catalogue items that are not already marked as downloaded. Download all ignores that status. Download selected downloads only your selection. ZIP Size controls the maximum part size when a large download is split into multiple ZIP files.

Folder options control the download folder and optional date/chat structure. Download status is organizer metadata inside the extension; it does not alter the source service.

Local Files

Choose a root folder, optionally add more roots, then use Scan when the folder contents change. Folder View browses the folder structure; All Media flattens the indexed results into one catalogue. Local file indexing does not require uploading the selected files to ChatGPT or Grok.

Organizer backup and clearing data

Export collections/ratings creates a JSON backup of organizer data such as collections, ratings, storyboards and canvases. Import restores that organizer backup.

Clear media catalogue only removes media catalogue/status data but keeps collections, ratings, settings and thumbnail cache so you can reconnect afterwards. The red Clear cache button is a stronger reset: it clears catalogue data and organizer data such as collections, ratings, storyboards and canvases. Neither button deletes the original files from ChatGPT, Grok or your computer.

Comic Canvas quick start

  1. Select media cards in the catalogue.
  2. Click New canvas and give the page a name.
  3. Click Add selected to place the selected media on the comic page.
  4. Click Open canvas to edit the page.

Panels and selection

Drag a panel to move it. Drag on empty canvas space to draw a selection box. Ctrl/Cmd-click adds or removes individual panels or bubbles from a multi-selection.

Fit shows the whole image inside the panel. Fill fills the panel and may crop the image. For a Fill panel, Shift-drag pans the crop and Shift-wheel zooms it. Front and Back change stacking order; Remove panel removes it from the canvas only.

Panel borders and custom shapes

Select a panel to reveal its border controls. You can change stroke width/color, use separate widths for individual sides, or enable Shape corners. When Shape corners is enabled, drag the four corner points to make diagonal, trapezoid or irregular comic panels. Reset controls restore the normal rectangle/border.

Speech and thought bubbles

Click Add bubble to create a bubble. Drag the bubble to move it and double-click it to edit its text. Select a bubble to show its controls. Tail type switches between Speech and Thought, while Bubble cycles through Oval, Cloud, Burst and Gear shapes.

For speech bubbles, drag the blue tail target to aim the tail at the speaker. Thought bubbles use a chain of thought dots. The detailed controls adjust tail width, curve, offsets, dot shape and other visual properties.

Secondary bubbles and bridges

A selected speech/thought bubble can have attached secondary bubbles. Use the secondary controls to add or edit their text. Bridge/merge controls can visually connect the main and secondary shapes for multi-part dialogue or linked thoughts.

Guides and editing precision

Hide guides hides selection outlines/handles for a cleaner page preview without deleting anything. Ctrl-click can extend canvas selection. When panel shape points are active, selecting two corner points and dragging one can move the pair together.

Saving and moving a comic page

Canvas data is stored as organizer data in the extension. Use Export JSON to make a portable backup of a canvas. Organizer Export also includes canvases. Importing organizer/canvas JSON restores the editable structure rather than flattening it into one image.

Storyboard note: the Storyboard toolbar is intentionally hidden in this build. Existing storyboard data and the underlying logic remain preserved.

No developer API key

AI Media Manager does not require an OpenAI or xAI developer API key. It works with the normal ChatGPT and Grok websites through the browser session in which you are already signed in.

This is why clicking Connect may need a normal ChatGPT/Grok tab: the extension uses the same signed-in web-session requests that the official page can make.

Passwords

The extension does not ask you to enter, save or share your ChatGPT/Grok password. Sign-in remains on the official source website and is handled by the browser/site. If you are signed out, Connect cannot retrieve private history until you sign in normally.

Where organizer data is kept

Catalogue metadata, collections, ratings, canvases and settings are kept in Chrome extension storage on the current browser profile. Local Files are indexed from folders you explicitly choose. AI Media Manager is not a separate cloud account and does not require an extra account of its own.

What network access is used for

The extension needs permission to access supported ChatGPT/Grok pages and their media hosts so it can read history metadata, load thumbnails/previews and download the media you request. Those source requests still go to the source services and their media hosts.

Local organizer actions such as collections and ratings do not need to be published back to ChatGPT or Grok.

Clearing data safely

Clearing extension data does not delete the original media from ChatGPT, Grok or your local folders. However, the red Clear cache action also clears local organizer information such as collections and ratings, so export organizer data first if you want a backup.

Practical safety note

No browser extension should be described as completely risk-free. Install AI Media Manager only from a copy you trust and review Chrome's requested permissions when installing it. The extension is designed so you do not need to provide API keys or passwords to use its normal catalogue features.

Press Esc or click outside the window to close.
